# Clean Reps Mobile agent notes

This repository owns Android-native capture, one canonical MediaMTX contribution source, reconnect/source-epoch behavior, local safe recording, athlete controls, tones and local TTS. It never adjudicates kicks or increments any official count.

This repository is PUBLIC (github.com/nohomedirectory/clean-reps-mobile). Never commit hosts, tailnet names or addresses, credentials, SRT connection strings, footage, frames or thumbnails; tests use `example.test` and `192.0.2.x`.

Before any gym use, run the owner device check (private runbook in clean-reps: `docs/runbooks/owner-device-check.md`).

Read `README.md` before changing transport. The launch contract is owned by `clean-reps/docs/tonight-sprint/million-kicks-launch.v1.json`; do not fork semantics here. Keep secrets out of the repository and make a missing publisher configuration block readiness rather than showing a false LIVE status.
